# GLODAPv2.2016b

The default dataset for the initial and boundary conditions for py-off-bgc is GLODAPv2.2016b. It can be downloaded from [here](https://glodap.info/index.php/mapped-data-product/#:~:text=Mapped%20Data%20Product%20files). Unzip the file and rename the directory as **GLODAPv2.2016b**.
